# BCC ArtGuard 

Интерактивный индикатор безопасности, написанный на Python с использованием библиотеки **Pygame**. Программа плавно переключается между безопасным статусом и режимом тревоги с красивыми анимациями и пульсацией.

##  Возможности
- Плавная смена визуальных состояний (переход между safe и danger режимами).
- Анимация пульсации для каждого состояния.
- Удобное управление с клавиатуры.

##  Управление
- **Пробел (Space)** — сменить статус (безопасно / подозрительная активность).
- **Esc** — выйти из программы.
